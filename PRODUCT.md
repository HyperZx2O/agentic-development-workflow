# PRODUCT.md

## Product Purpose

An interactive, scroll-driven guide that turns the "Agentic Development Workflow" README into a phase-by-phase walkthrough. It teaches beginner-to-intermediate hackathon participants how to run a structured, prompt-driven AI-assisted build: front-load every decision into docs (idea.md, spec.md, plan.md), then execute phase by phase with a coding agent and a human review at every transition.

## Users

- **Hackathon beginners** who skip dense READMEs. They want to *see* the workflow, not parse a wall of prose.
- **Solo builders and small teams (1-4)** starting with AI coding agents and looking for a repeatable process.
- **Judges / curious readers** who want a fast, visual understanding of the method without reading the original guide.

## Brand / Tone

Confident, technical, slightly nocturnal. "The discipline of a big engineering team, without the overhead." Dark canvas with warm molten-brass accents, instrument-grade apparatus imagery, mono technical labels. Verb-driven, declarative copy. Not corporate, not pastel, not marketing-ese.

## Register

brand. The design *is* the product here. The site's visual craft is part of the teaching.

## Anti-references

- Generic "AI SaaS" dark-blue gradient heroes with glassmorphism cards.
- Generic agency "clean and modern" with beige + muted slate.
- Overwrought dev-tool pages: neon on black, particle systems, rotating orbs.
- Fake browser/IDE chrome screenshots.

## Strategic Principles

1. **Front-load, then execute.** The site's own structure mirrors the workflow it teaches: idea → spec → plan → build → review.
2. **Phase-by-phase progression.** The scroll journey IS the argument. Every phase has a prompt you can copy and an exit condition you can check.
3. **Show, don't tell.** Each phase's prompt is a real copyable block; the site is immediately usable, not just readable.
4. **Restraint with intent.** One focal apparatus, one warm accent, one display face. Dark, calm, precise.
5. **The spec is the hero.** The single most important lesson: write down what you're building before you build it.
